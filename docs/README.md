# F-Cinema Documentation Index

Đây là điểm vào chung cho tài liệu kỹ thuật và kế hoạch phát triển của F-Cinema.

- [`../AGENTS.md`](../AGENTS.md): quy tắc bắt buộc trước khi sửa code.
- [`PROJECT_CONVENTIONS.md`](PROJECT_CONVENTIONS.md): kiến trúc, convention và decision đã duyệt.
