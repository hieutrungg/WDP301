## Deferred / Unfinished SRS Requirements

### Cancellation / Refund

Owner approved the demo policy on 2026-10-27: Customer requests close 45 minutes before showtime; checked-in tickets are ineligible; refundable value is ticket price plus F&B not yet `FULFILLED`; fulfilled F&B is excluded; there is no service fee or monthly limit. Manager alone approves/rejects. Digital methods use an idempotent `MockRefundProvider` representing return to the original method; counter cash is recorded as manually returned outside the system.
